# School Backpack Checklist

A daily list of what students should pack in their school backpack.

> Free printable & editable version: [School Backpack Checklist on ChecklistForge](https://checklistforge.com/checklist/school-backpack-checklist) — tick items online or download as PDF.

## Daily essentials

- [ ] Pack the student planner or assignment notebook.
- [ ] Add a pencil case with pencils, pens and an eraser.
- [ ] Include a small ruler and a highlighter.
- [ ] Add hand sanitizer and a pack of tissues.
- [ ] Pack any keys, ID card or bus pass needed. — _Keep these in the same pocket every day._

## Books and class materials

- [ ] Check the timetable and pack only that day's subjects.
- [ ] Add completed homework and any assignments due.
- [ ] Include the right notebooks, folders and binders.
- [ ] Pack any textbooks or reading books required.
- [ ] Add signed forms or notes to return to the teacher.
- [ ] Remove papers and books not needed today.

## Technology

- [ ] Add the fully charged tablet, laptop or Chromebook.
- [ ] Pack the charger if the device may run low. — _Many students forget the cable, not the device._
- [ ] Include labeled headphones or earbuds.
- [ ] Add a calculator if a class requires one.
- [ ] Confirm any required logins or files are ready.

## Food and water

- [ ] Pack lunch or lunch money in a known pocket.
- [ ] Add a healthy snack for break time.
- [ ] Fill a sealed, reusable water bottle.
- [ ] Include any utensils or napkins needed.
- [ ] Pack any medication or snack for medical needs.

## Day-specific items

- [ ] Add gym kit and sports shoes on PE days.
- [ ] Pack returned library books on library day.
- [ ] Include instruments or music folders for lessons.
- [ ] Add project materials or items for show and tell.
- [ ] Pack appropriate gear for after-school clubs.
- [ ] Include weather items like an umbrella or sunhat.
