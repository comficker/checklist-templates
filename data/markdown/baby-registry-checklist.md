# Baby Registry Checklist

What to add to your baby registry, organized by category.

> Free printable & editable version: [Baby Registry Checklist on ChecklistForge](https://checklistforge.com/checklist/baby-registry-checklist) — tick items online or download as PDF.

## Nursery & Sleep

- [ ] Register for a crib or bassinet that meets current safety standards
- [ ] Add a firm, well-fitting crib mattress
- [ ] Include three or four fitted crib sheets
- [ ] Add a few wearable blankets or sleep sacks in newborn size — _Skip loose blankets, pillows, and bumpers for the sleep space._
- [ ] Register for a baby monitor that fits your home
- [ ] Add blackout curtains and a small night light

## Feeding

- [ ] Register for bottles in a couple of sizes to see what your baby prefers
- [ ] Add a bottle brush and a drying rack
- [ ] Include burp cloths, at least eight to ten
- [ ] Register for a nursing pillow if you plan to breastfeed
- [ ] Add a breast pump and storage bags if pumping is part of your plan — _Check your insurance, as a pump may be covered._
- [ ] Include several bibs for the early months
- [ ] Add a few cans or supply of formula if you plan to use it

## Diapering

- [ ] Register for newborn and size 1 diapers in a few packs
- [ ] Add fragrance-free wipes in bulk
- [ ] Include a changing pad with a washable cover
- [ ] Register for a diaper pail or sealed trash system
- [ ] Add diaper cream and a small basket to keep supplies handy
- [ ] Include a portable changing kit for the diaper bag

## Clothing & Layette

- [ ] Register for short- and long-sleeve onesies in 0 to 3 and 3 to 6 months
- [ ] Add footed sleepers with easy snaps or zippers
- [ ] Include socks, hats, and scratch mittens
- [ ] Add seasonally appropriate layers like a sweater or bunting
- [ ] Register for a few swaddle blankets
- [ ] Include extra burp cloths and washcloths

## Travel & Gear

- [ ] Register for an infant car seat that fits your vehicle
- [ ] Add a stroller, or a travel system that pairs with the car seat
- [ ] Include a baby carrier or wrap
- [ ] Register for a roomy, washable diaper bag
- [ ] Add a portable play yard for naps away from home

## Bath & Grooming

- [ ] Register for a baby bathtub or a sink insert
- [ ] Add hooded towels and soft washcloths
- [ ] Include fragrance-free baby wash and lotion
- [ ] Add a soft hairbrush and baby nail clippers or a file
- [ ] Include a digital thermometer — _Ask your pediatrician which type they recommend for a newborn._

## Safety & Health

- [ ] Register for outlet covers and cabinet latches for later use
- [ ] Add a baby gate if you have stairs
- [ ] Include a nasal aspirator for stuffy noses
- [ ] Register for a basic baby first aid kit
- [ ] Add a humidifier for dry-air seasons
- [ ] Include a fitted, breathable mattress protector
